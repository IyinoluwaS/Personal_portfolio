Syllo

Syllo turns Canvas course exports into a clear view of the semester. I led the backend: a pipeline that takes Canvas EPUB course exports, converts them into structured academic information, and feeds a semester dashboard. The backend runs on FastAPI with Pydantic models and SQLite, using NVIDIA Nemotron for extraction; the dashboard is built in React and TypeScript.

Applied AI · Text-to-SQL

Ledger Agent

Ledger Agent answers natural-language questions about financial data by turning them into validated SQL queries. Built with LangGraph over SQLite, it repairs failed queries automatically, which raised accuracy from 62% to 94% on a 16-question evaluation. I also built an evaluation and ablation framework to study failure patterns and compare repair strategies.

02 — Selected projects

Things I’ve built

SteelHacks XIII · Two-person team

Syllo

Syllo turns Canvas course exports into a clear view of the semester. I led the backend: a FastAPI pipeline that converts Canvas EPUB exports into structured deadlines, exams, schedules and course policies. NVIDIA Nemotron does the extraction, and every result is checked against Pydantic schemas and quoted sources, so unsupported data is rejected. The parser is hardened against path traversal, XML external entities and zip bombs.

Dental Time Machine

Applied AI · Text-to-SQL

Ledger Agent

Ledger Agent answers natural-language questions about financial data by turning them into validated SQL queries. Built with LangGraph over SQLite, it repairs failed queries automatically, which raised accuracy from 62% to 94% on a 16-question evaluation. I also built an evaluation and ablation framework to study failure patterns and compare repair strategies.
